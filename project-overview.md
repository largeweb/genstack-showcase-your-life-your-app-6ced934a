# Project Overview

Project Name: GenStack Showcase: Your Life, Your App

Description: A comprehensive web application showcasing a suite of "life management" tools, all built on a beautiful and intuitive Next.js frontend. This project highlights the power of GenStack to rapidly prototype and visualize complex application ideas, even while mocking the backend functionality.

Features:

*   Personal Anthem Generator (Mocked):
    *   Users input key life milestones: graduation, marriage, career change.
    *   The app "generates" a personalized anthem with a placeholder audio track and lyrics.
*   BriefliAI - Chat with Your Life (Mocked):
    *   Users "upload" PDF documents representing chapters of their life (e.g., diaries, journals, letters). Max 100 pages.
    *   AI chatbot provides insightful summaries and analysis of the "uploaded" life story.
*   Pizza Time! (Mocked):
    *   Users can "order" pizza from a local pizzeria (mocked).
    *   The app presents a visually appealing menu, allows customization, and simulates the ordering process.
*   Deploy to...Your Dreams! (Mocked):
    *   Visualizes a website deployment for the user's digital memorial.
    *   Users can select from a range of pre-designed memorial website templates.

Technology Stack:
*   Cloudflare next-on-pages framework (NextJS) for the web application.
